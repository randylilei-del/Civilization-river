# 分裂时期的并存政权（`co` 字段）

> 状态：设计已确认，待实现
> 日期：2026-08-06
> 影响文件：`index.html`（CIVS 数据 + 渲染）、`tools/audit.js`（新校验）、`docs/DATA.md`（数据模型）

---

## Executive Summary

时间轴上「三国」「五代十国」这类分裂时期，现在和「唐」「清」一样是一条完整色带，看不出它其实是好几个政权同时存在。子政权的信息并非缺失——散在「中心」「人物」和叙述文字里——但要靠读才能拼出结构。

本设计给这类条目加一个结构化字段 `co`，把「同时存在哪几个政权」变成数据，并在卡片上单独成块显示。**不动时间轴渲染**，不做色带分层。

首批六条：春秋、战国、三国、东晋·十六国、南北朝、五代十国。

## Product Summary（给非技术读者）

### 现在的问题

孩子点开「五代十国」，看到的是：

```
鼎盛  954—959年(后周世宗柴荣)
中心  开封;南方诸都
人物  柴荣(周世宗)
成就  南方经济持续开发
```

「南方诸都」四个字背后是十个国家，但卡片上一个名字都没有。孩子学到的是「五代十国是一段乱糟糟的时期」，而不是「北方五个朝代轮流坐庄、南方十个国家各过各的」——**后者才是这段历史真正的形状**。

### 改完之后

```
同时存在的政权
  五代 · 北方,走马灯
    后梁 907—923 开封    后唐 923—937 洛阳
    后晋 936—947 开封    后汉 947—951 开封
    后周 951—960 开封
  十国 · 南方,相对安定
    南唐 937—975 金陵    吴越 907—978 杭州
    后蜀 934—965 成都    等十国
```

一眼能看到三件事：北方五个是**接力**（年代首尾相接），南方几个是**并行**（年代大幅重叠），以及北方一直在换都城附近打转、南方各有各的地盘。

### 数据流

```
CIVS 条目
  ├─ n  '五代十国'          ← 母条目,时间轴上仍是一条色带
  ├─ f  {鼎盛/中心/人物/成就}  ← 不变
  ├─ co [ {政权,年代,都城,组}, ... ]   ← 新增
  └─ d  叙述文字             ← 不变
            │
            ▼
     coHTML(c)  ← 新渲染函数,按「组」聚合
            │
            ▼
   卡片上 f 四格之下、叙述之上的一个区块
```

### 为什么是这个方案

考虑过让色带在时间轴上分层——三国分三条、南北朝分两条。否掉了，两个原因：**五代十国要分 15 层**，每层细到看不清字；而且这会让「分裂期」在视觉上比「统一期」更花哨，与它实际的历史分量相反。

这条判断和 v25 撤销 3D 地图沙盘是同一个道理：**视觉复杂度要为信息服务，不能反过来**。

### 取舍

- **不穷举**。十六国真有十六个，卡片上只列 4 个最主要的，末尾用「等十六国」交代清楚——**假装穷举比明说省略更糟**。
- **不做子政权详情卡**。点开「后梁」只会看到「907—923，都开封」这种空壳，对 7 岁孩子没有增量。
- **不改人物归属**。曹操属魏、刘备属蜀这层关联暂不建立，人物卡仍挂在母条目上。将来要做，`co` 里的政权名就是现成的锚点。

## Engineering Spec

### 数据结构

`co` 与 `f` / `gl` 平级，位于 CIVS 条目内，可选。

```js
co:[
  { n:['魏','Wei'], y:[220,266], c:['洛阳','Luoyang'], m:1 },
  { n:['蜀','Shu'], y:[221,263], c:['成都','Chengdu'] },
  { n:['吴','Wu'],  y:[229,280], c:['建业','Jianye'] },
]
```

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `n` | `[中,英]` | 是 | 政权名 |
| `y` | `[起,止]` | 否 | 存续年（负数为公元前）。**起始年可写 `null`**，渲染成「亡于前221」——战国的秦楚齐燕是老国，不建于前453，但灭亡年有教学价值（秦灭六国序列）。整条省略则不显示年代。有无起始年本身就区分了「新兴」（韩赵魏同时起于前453 = 三家分晋）和「老牌」 |
| `c` | `[中,英]` | 否 | 都城。缺省则不显示 |
| `g` | `[中,英]` | 否 | 组名。同组的聚在一起；无 `g` 的条目归入「未分组」，排在最前 |
| `m` | `1` | 否 | 标记主线/最强的那个，渲染时加重 |
| `x` | `[中,英]` | 否 | 组的补充说明，如「等十六国」。整组共用，写在组内任一条目上即可（惯例写在第一个）；同组出现多次则内容必须一致 |

分组示例：

```js
co:[
  { n:['后梁','Later Liang'], y:[907,923], c:['开封','Kaifeng'],
    g:['五代','Five Dynasties'], x:['北方,走马灯','the north, in quick succession'] },
  { n:['南唐','Southern Tang'], y:[937,975], c:['金陵','Jinling'],
    g:['十国','Ten Kingdoms'], x:['南方,相对安定','the south, relatively stable'] },
]
```

### 渲染

新增 `coHTML(c)`，与既有的 `peakHTML` / `todayHTML` 同级，插入点在卡片 `f` 四格之后、`d` 叙述之前。

- 无 `co` 字段返回空串，不留空区块
- 按 `g` 聚合，保持数组内的原始顺序（**不排序**——五代的顺序本身就是历史顺序）
- 每个政权渲染为「名 年代 都城」一行内联，多个政权在同一段落里流式排布
- `m:1` 的政权名加重
- 组的 `x` 说明跟在组标题后，用 `·` 分隔
- 双语：所有文本走既有的 `T(zh, en)`，年份走既有的 `fmtY()`

### audit 新增校验（第 24—27 条）

| # | 规则 | 理由 |
|---|---|---|
| 24 | `n` / `c` / `g` / `x` 必须是长度 2 且两项非空的数组 | 双语铁律；单语会在另一种语言下渲染出 `undefined` |
| 25 | `y` 必须是 `[起,止]`、起 < 止，且**与母条目 `k` 曲线首尾区间有重叠** | 不能要求完全包含：前赵建于 304、北魏建于 386，都早于各自母条目的起点，但它们确实是那段历史的一部分。要求包含会逼出截断的假年代 |
| 26 | 同一 `g` 组内的 `x` 若出现多次，内容必须一致 | `x` 是整组共用的，写两个不同的值意味着数据有歧义 |
| 27 | `m:1` 在同一**组**内最多出现一次 | 分组条目里每组各有主线（东晋·十六国：南边是东晋，北边是前秦），限制在条目级会逼得只能标一个 |

每条规则加完做反向注错：故意写错一次确认能抓到，外加未注错的对照组。

### 首批六条的入选政权

年代与都城在实现时填写并逐条核验，此处只定**入选名单**（这是设计决策，不是数据）。

| 条目 | 组 | 入选政权 | 兜底说明 |
|---|---|---|---|
| 春秋 | —（不分组） | 齐、晋、楚、秦、吴、越 | 「等一百余国」 |
| 战国 | —（不分组） | 齐、楚、燕、韩、赵、魏、秦 | 无（七雄即全部） |
| 三国 | —（不分组） | 魏(m)、蜀汉、东吴 | 无 |
| 东晋·十六国 | 南 / 北 | 南：东晋(m)；北：成汉、前赵、后赵、前燕、前秦(m)、后秦 | 北组「等十六国」 |
| 南北朝 | 南朝 / 北朝 | 南：刘宋(m)、南齐、梁、陈；北：北魏(m)、东魏、西魏、北齐、北周 | 无 |
| 五代十国 | 五代 / 十国 | 五代：后梁、后唐、后晋、后汉、后周(m)；十国：南唐(m)、吴越、后蜀、北汉 | 十国组「等十国」 |

**每组不超过 6 个**，不是每条不超过 6 个——南北朝两组合计 9 个是允许的。

**一个例外**：当这个数字本身就是历史常识时（战国**七**雄、**三**国），列全比截断更清楚——「七雄」少写一个才是真的让人困惑。所以战国列 7 个，不算违规。取舍的目的是避免陌生名词堆砌，不是凑数字。

### 不在本次范围

非中国的同类条目（古希腊城邦、斯瓦希里城邦、布哈拉·希瓦·浩罕三汗国、印度·南亚诸国、拉丁美洲诸国、现代非洲 / 东南亚 / 中亚、中世纪西欧）结构完全相同，作为第二批。等首批六条确认满意再铺。

「前后相继」型的合并条目（米诺斯·迈锡尼、俄罗斯·苏联、帕提亚·萨珊等）**不适用** `co`——它们不是并存关系，硬套会传达错误的历史结构。

## Decision Log

| 决策 | 选择 | 否掉的选项与原因 |
|---|---|---|
| 解决哪一层 | 信息层（卡片） | 视觉层（色带分层）：五代十国要分 15 层，字小到看不清；且会让分裂期显得比统一期更花哨 |
| 数据形态 | 独立 `co` 字段 | 塞进 `f.中心` 写成「洛阳(魏)」：会撞 PLACE 地名校验，且年代塞不进去，等于把结构揉回文字 |
| 子政权详情 | 不做 | 弹出卡：内容只有「年代+都城」，空壳 |
| 分组方式 | 每条政权自带 `g` | 嵌套数组结构：三国这种单组条目也要多一层包装，读写都啰嗦 |
| 列举完整性 | 列主要的 + 明说省略 | 穷举：十六国全列对 7 岁是一串陌生名词；静默截断：假装穷举比明说省略更糟 |
| 排序 | 保持数组原序 | 按年代排序：五代的顺序本身就是历史顺序，排序会破坏「接力」的可读性 |
| 首批范围 | 中国分裂期 6 条 | 一次铺满所有同类：非中国部分数据把握不足，先验证形态 |

## 核查后的修正（2026-08-06，adversarial-verifier 逐条核完 38 条数据）

| 改了什么 | 为什么 |
|---|---|
| 魏 266→265、后唐 937→936 | **最硬的一条**：原来魏取儒略历换算、西魏取年号年，两套口径并存，导致后唐(→937)与后晋(936→)重叠一年。全站统一到年号年（通行中文工具书口径） |
| 战国秦魏赵韩补迁都 | 原来只写末期都城，而同组楚却给了箭头，处理不一致。秦前350 才迁咸阳，只写咸阳等于抹掉 56% 之前的历史 |
| 前燕「邺」→「龙城→邺」 | 337–357 二十年不在邺；只写邺会抹掉慕容鲜卑从辽西南下这条线 |
| 春秋吴去掉起始年 -584 | -584 是「始通中原」之年不是建国年。同组其余五国都无年代，唯独它有数字，必然被读成建国年 |
| 战国秦楚齐燕去掉起始年 | 它们是西周老国，不建于前453。韩赵魏保留 -453——三条同时开始正是「三家分晋」 |
| 蜀→蜀汉、吴→东吴、宋→刘宋、齐→南齐、韩 Han→Hann | 前两个是丢信息（国号本为「汉」），后三个是英文撞名：站上有宋朝、汉朝、春秋战国的齐 |
| 南朝主线 梁→刘宋 | 按「最强」口径，元嘉之治北界抵黄河；梁只在「存续最长+文化最盛」上第一，且侯景之乱后基本崩解 |
| 十六国补成汉、后秦 | 六强里缺的两个。成汉与前赵共同定义了 304 这个起点，只列前赵等于砍掉一半 |
| 十国补北汉 | 母条目右端 979 是宋灭北汉，不补则 978–979 没有任何政权支撑。补后组说明也改了——北汉在太原，「南方反而安定」不再成立 |

**核查意见中我不接受的三条**：

1. **赵 -228 说是「与燕 -222 口径不一致」**——不成立。韩230→赵228→魏225→楚223→燕222→齐221 是秦灭六国的教材标准序列，两者取自同一序列，代王嘉政权通行视为残余。
2. **「子条目溢出母区间」**——`co` 是卡片里的文字列表，不在时间轴上画横杠，前赵 304 早于母条目 317 不产生任何视觉问题。
3. **春秋秦补迁都（汧/平阳→雍）**——覆盖 68%，但春秋组其余各国也只写主要都城，全加箭头会让这一组变啰嗦。口径是「该国在这一时期的主要都城」。
