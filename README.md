# 文明长河 · A River of Civilizations

从史前到现代的世界文明兴衰交互图(单文件 PWA)。

An interactive, bilingual (中/EN) visualization of the rise, fall and exchanges
of world civilizations from prehistory to the present — a single self-contained
HTML file with offline support.

- 泳道 = 8 个地理区域(自东向西),色带厚度 = 相对影响力,颜色 = 文明圈
- 点击文明:详情卡(兴衰曲线 / 鼎盛期版图 / 大事记 / 维基链接)
- 传播追踪:青铜、佛教、火药、哥伦布大交换等 10 条跨文明传播线
- 时间轴缩放:点时代名或拖选区间

Deployed as a static site (Vercel / any static host). Coastline data embedded
from [world-atlas](https://github.com/topojson/world-atlas) 110m (Natural Earth, public domain).
