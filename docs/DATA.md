# 数据模型与增改指南

全部数据在 index.html 的 <script> 内,均为常量表。改动后务必:语法检查 → `node tools/audit.js` → 渲染验证 → 双语同步(完整工作流见 CLAUDE.md)。

`tools/audit.js` 自包含、无依赖,直接从 index.html 抽表,查下面这些约定是否被破坏:中英条目数对齐、大事记越界与排序、CHRONO_X 双语完整性与同年重复、GL 区间越界与 k 值合法性、按名索引表的孤儿键、泳道 id 有效性。

## 表清单

| 表 | 结构 | 说明 |
|---|---|---|
| `LANES` | {id, name} | 泳道,按经度自东向西;新泳道按经度插位 |
| `SPHERES` | {name, v(CSS变量名)} | 文明圈;新增需配色 + 色盲校验 |
| `CIVS` | {l, s, v, n, k, b, f, d, gl?} | 文明主表。l=泳道 s=文明圈 v=色深0/1/2 k=[[年,影响力]]关键帧 b=一句话 f=速览{鼎盛/中心/人物/成就} d=叙述 gl=鼎盛区间(可选) |
| `gl` 子表 | {a, b, k, t:[zh,en], d:[zh,en]} | k∈econ/art/tech/thought;t/d 自带双语 |
| `EVENTS` | {y, ls, t, n, d} | 交流事件;ls=涉及泳道 t∈war/trade/culture/tech/plague/migration |
| `TRACES` | {n:[zh,en], stops:[{y,l,t:[..],d:[..],p?}]} | 传播轨迹;stops 按年排序,p=上游节点索引(默认前一个) |
| `GEO` | {'文明名': {p:[[[lon,lat]..]..], c:[lon,lat]}} | 鼎盛期示意版图(可多多边形)+ 核心点;键=CIVS.n |
| `CHRONO` | {'文明名': [[年,标题,一句话]..]} | 大事记(中文) |
| `EN` | lanes/spheres/eras/evtype/events/civ/chrono | 英文字典;events/chrono 按索引与中文对齐,**数量必须一致** |
| `VIDEO` | {'文明名': {b?:BV号, y?:YouTube ID, t:[zh,en]}} | 纪录片,**人工策展**。b/y 至少给一个;中文界面优先 B 站、英文优先 YouTube。**绝不可凭印象生成 ID**——编出来的要么死链、要么指向无关内容,而用户是小孩。没条目的文明只显示搜索按钮 |
| `RIVERS` | {n:[zh,en], p:[[lon,lat]..]} | 河流折线(不闭合),约 35 条。手写粗略坐标 ±1~2° |
| `RANGES` | {n:[zh,en], p:[[lon,lat]..]} | 山脉闭合多边形,约 20 条 |
| `DESERTS` | {n:[zh,en], p:[[lon,lat]..]} | 沙漠闭合多边形,约 8 条 |
| `PEOPLE` | {'中文人名': {g,y,yk?,ca?,r?,c,n,t,a,s,w?}} | 人物卡 217 条,**人工策展**,已覆盖全部「人物」字段。g=类别 y=[生,卒] c=所属文明 n/t/s=双语 a=双语「三件事」。**yk**:生卒不详时 y 的真实含义——`'r'`=在位、`'a'`=活跃(与 r 互斥,audit 查);**ca**=年代为约值。键=中文人名,英文界面靠**位置**换回中文键 |
| `PGLYPH` / `PGNAME` | {类别: 字形} / {类别: [zh,en]} | 八类:king 帝王/state 政治/war 征战/mind 思想/sci 科学/art 艺术/faith 宗教/sail 航海。「思想」只给真正的思想家,治国者归「政治」 |
| `PEAK` | {'文明名': {a?, p?, w?}} | 鼎盛期硬数字。a=版图(万 km²) p=人口(万) w=占当时世界人口(0~1,渲染成 1/N)。三项都可缺,**没有可靠估算就整条不写**。**口径一致比单个数字精确更重要**:版图统一用 Taagepera 帝国面积序列,人口以公认峰值估算为准(中国各朝优先用官方户口数)。混用来源会让"谁大谁小"失去意义 |
| `PLACE` | {'古地名': [国zh, en] 或 [国zh, en, 今名zh, en]} | 古都今属何处。键=`f['中心']`里的中文原文(精确匹配,含括号);**中英共用这一套中文键**,不会两边跑偏。四项=今天仍有对应城市,两项=遗址或泛指区域 |
| `WIKI_NAME` / `EN.civ[n].w` | 消歧义映射 | 中文歧义名(明→明朝)/英文歧义名(Ming→Ming dynasty) |
| `LAND` | 压缩海岸线环 | 生成自 world-atlas land-110m,勿手改 |

## 常见操作

- **k 关键帧的首尾约定**:已消亡的文明首尾帧影响力都写 0(色带两端收窄成尖);**存续至今的文明末帧保持非 0**(如共和国 .9、美国 .95),色带在 2025 右边缘齐平截断——这是刻意的,别"修正"成 0。
- **大事记年份必须落在 k 的首末年之间**,否则曲线上画不出锚点(`sparkSVG` 直接跳过越界节点),只在列表里出现。历史年份早于色带起点时,应前移色带起点而不是改年份。
- **加纪录片**:先自己看过、确认视频确实在讲这个文明、画质时长过得去,再往 `VIDEO` 加一行。B 站 BV 号取自视频链接 `bilibili.com/video/BV…` 那一段。**iframe 是点击后才插入的**,所以不加视频、或用户不点,页面对外零请求——离线缓存与"不引入外部资源"的铁律都不受影响。
- **加地理要素**:往 `RIVERS`/`RANGES`/`DESERTS` 加一条即可,地图会自动画(只画与视野相交的)。**河名的标注条件是"至少两个点落在本文明版图多边形内"**——加了新河却不见名字,先查是不是版图多边形没覆盖到,而不是去放宽判定;放宽会让埃及标上幼发拉底河。
- **找泳道的断流**:按年扫一遍某泳道在场的文明(取 k 插值 >0.02),空场时段就是内容缺口。v15 靠这招发现草原·中亚有四段共 775 年完全空白。**别靠看图估**——压缩的古代时间轴会让空档显得比实际短。
- **色深 v 的分配规则**:只在「同泳道 + 同文明圈 + 时间重叠」三者同时成立时才需要错开;跨圈不必管(颜色本来就不同)。加色带前先列出时间上与它重叠的同圈色带,再挑没被占用的 v。
- **标签会被抑制**:色带厚度 <13px 或横向宽度 <52px 时不画名字(`buildChart` 里的规则,防重叠)。古代段时间轴压缩厉害,一个 120 年的色带只有约 47px,拿不到标签——这是有意的,不是 bug;该色带仍可悬停/点击。
- **每个文明至少要有一个人物**(v28 定的标准):115 个里 108 个有。**剩下 7 个是真的没有名字可写**——印度河文明、二里头·夏、米诺斯·迈锡尼、奥尔梅克、查文文化、瓦里·蒂瓦纳科、大津巴布韦,全部是无同时代文字记录的考古文明,**这 7 个留空是正确状态,不要为了凑数编人名**。特奥蒂瓦坎不属于这一档:它的统治者名字见于玛雅碑文(与加纳帝国只见于阿拉伯地理学家同理)。**给文明加「人物」字段要中英两侧同时插入且逐个对齐**,注意 `f:{'中心':'…'}` 可能是唯一字段、末尾无逗号,以及 `Siyaj K'ak'` 这类英文名里的撇号必须转义。
- **加人物卡**:`PEOPLE` 加一条即可,人名会自动从维基外链变成站内弹卡。写作格式固定为**「一句话身份 + 他做了三件事 + 意义」**——三件事对小孩最好读;第三段写**客观成就与地位**(世界之最、后世沿用多久、是否列入世界遗产这类可核查的事实),**不要写成因果推论**。v26 最初按「所以」的因果口径写,Ray 判定"太深刻",v26.1 全部重写过一遍。**键用中文人名,英文界面靠位置换回中文键**,所以 `EN.civ[n].f.Figures` 必须与中文「人物」逐个对齐(audit 查这一条;隋原本写成 "Emperors Wen and Yang" 合并了两个人,v26 拆开了)。没配 PEOPLE 的人名保持维基外链行为,两者视觉上靠「浅底片 vs ↗箭头」区分。
- **加古都的"今属何处"**:在 `f['中心']` 里写古地名,再去 `PLACE` 补一条。渲染时按今属国家归并(`todayHTML`),所以「长安、洛阳」出来是「今 中国:西安、洛阳」而不是重复两遍国名。**遗址类条目只写两项**(没有对得上的今日城市);但要注意:同一文明里若一个遗址与一个有今名的城市落在同一国家,遗址会被归并吞掉——这时给遗址补一个「XX近郊」当今名。`node tools/audit.js` 会查 PLACE 缺条目、孤儿条目、中英"中心"地点数不等。
- **加一个文明**:CIVS 加条目(影响力峰值参考同泳道对比)→ GEO 加版图 → CHRONO 加大事记 → EN.civ + EN.chrono 加英文 → 歧义名进 WIKI_NAME
- **加传播轨迹**:TRACES 加条目即可(选择器自动出现),节点 t/d 双语内联
- **调影响力曲线**:只改 k;注意同泳道同期堆叠总和(超限会自动压缩,峰值别全 1.0)
- **拆分色带**(参考 v10 中国拆分):新条目替换旧条目;GEO/CHRONO/EN 同步换键;旧键残留无害但建议清理
