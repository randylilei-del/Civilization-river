# 兴衰六问 · 撰写规范（撰写者必读全文）

给 7 岁孩子（及其家长）的世界文明可视化网站写「兴衰六问」。六个问题固定：
born=为什么出现 · rule=靠什么统治 · money=靠什么赚钱 · power=靠什么变强 · fall=为什么衰落 · legacy=留下什么

## 输出格式（严格遵守）

写一个 JSON 文件，顶层是对象，键=文明名（与输入 JSON 的 `n` 完全一致，一字不差），值=六键对象，每键 `[中文, 英文]`：

```json
{
  "文明名": {
    "born": ["中文2-4句", "English 2-4 sentences"],
    "rule": ["...", "..."],
    "money": ["...", "..."],
    "power": ["...", "..."],
    "fall": ["...", "..."],
    "legacy": ["...", "..."]
  }
}
```

- 六键必须齐全。某一问实在无法诚实回答 → 整条文明跳过，放进顶层 `"__skipped": {"文明名": "原因"}`，宁缺毋错。
- 中文用中文标点逗号句号（,。分号;），不要英文逗号混排；英文自然流畅，不要翻译腔。
- JSON 内正常写引号撇号即可（插入脚本负责转义），但不要用未转义的双引号嵌在字符串里（用「」或单引号）。

## 三条铁律（违反 = 返工）

1. **只写教科书主流共识，不写单因论。** 「X 亡于某一件事」式的一句话归因禁止；fall 一律多因叠加。小众学说、翻案观点不写。
2. **有争议的因果标「主流看法是/一般认为/据记载」**，不装确定。真的没有定论就明说（例：印度河文明的衰落「尚无定论，主要假说是气候变化与河流改道」——诚实的不知道比编造的知道好）。
3. **先机制后事件。** 每段 2–4 句：第一句说机制（制度/经济/地理的逻辑），后面用事件落地。允许一个记忆钩子式收束句（「堡垒是从里面打开的」），但钩子必须是主流叙事的压缩，不是个人妙语。

## 已被核查员抓过的错型（前车之鉴，逐条自查）

- **盛世×大数错误配对**：「康雍乾…人口涨到四亿」——四亿是道光年间的事。凡是「时代+数字」的组合，核对数字属于哪个时代。
- **精确数字挂错锚点**：「三年拆完帝国」——三年只对得上其中一段。写精确数字前确认起止点。
- **「最后一步」类时序断言**：凯撒渡河之后内战还打了二十年。「最后/第一/唯一」这类词用前必查。
- **胜利者史料当客观事实**：纳波尼德失民心主要出自波斯记载 → 标「据流传下来的记载」。
- **流行说法≠学界定论**：「新航路掐死奥斯曼」「印刷术经蒙古西传」都写不得或要限定。
- **口径虚高**：「普通法覆盖近半法域」实为约三分之一人口。

## 与已有卡片内容的关系

输入 JSON 里每条带 `b`（一句话）、`f`（速览四格）、`d`（叙述段）、`co`（并存政权名）、`peak`（版图/人口硬数字）。**六问不得与它们矛盾**；可以引用（「版图峰值 540 万平方公里」须与 peak 一致），不要重复大段转述 d 的内容——六问是分析层，d 是故事层。

## 敏感条目（涉及则遵守）

- 民国：只陈述可核查事实（内战失败、迁台），不下政治判断，不用褒贬词。
- 朝鲜半岛：fall=1910 日本吞并，写事实即可。
- 殖民条目（欧洲殖民非洲/东南亚、西葡殖民美洲、英属印度）：殖民的掠夺性如实写（这是主流共识），独立运动如实写，不美化不咆哮。

## 范例（试点已上线并通过核查的两条，语感对齐它们）

**罗马帝国**
- born: 百年内战证明,为一座城设计的共和制度管不住横跨三洲的疆土;屋大维保留共和的名义、收走实际的权力,精疲力竭的社会接受了这笔交易:用自由换和平。
- fall: 主流看法是多因叠加而非单一原因:边防开支压垮财政,银币掺假引发通胀,瘟疫削减人口,迁徙的民族不断叩边;东西分治后,税基薄弱的西部先撑不住。

**唐**
- money: 前期均田制配租庸调:国家分地,农民纳粮服役;安史之乱后改两税法按资产征税,财政靠江南漕运撑起。
- fall: 均田制在人口增长与土地兼并下失灵,府兵随之枯竭;改募兵又让边镇节度使拥兵自重,安史之乱砍断王朝脊梁;此后中央与藩镇共治一百五十年,黄巢起义烧完了财政根基。
