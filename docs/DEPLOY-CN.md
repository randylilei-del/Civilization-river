## 一、代码要改什么：什么都不用改

逐项确认过：

| 项 | 现状 | 换域名后 |
|---|---|---|
| `manifest.webmanifest` | `start_url` / `scope` 都是 `./`，图标相对路径 | 照常工作 |
| `sw.js` | 用 `self.location.origin` 判断同源，资产清单全是相对路径 | 照常工作 |
| `index.html` | 单文件，无构建、无后端、无外部 JS/CSS | 照常工作 |
| 仓库结构 | 根目录即站点根，没有 `dist/` | 输出目录留空即可 |

**结论：把仓库原样接上另一个静态托管就能跑。** Vercel 那份保留不动，双份部署互不影响。

## 三、⚠ 卡在这里：国内访问返回 401

### 实测数据（2026-08-14，直连边缘节点 IP + SNI，绕过本机代理）

| 请求 | 国内节点<br>124.72.129.118 | 海外节点<br>43.174.246.29 |
|---|---|---|
| 干净 URL，不带任何 token/cookie | **HTTP 401**（123ms） | **HTTP 200**，2362KB |
| 带 `?eo_token=…&eo_time=…` | **302 → 种 cookie → 200** | — |

带 token 之后国内节点的完整下载：

| 国内节点 | 首字节 | 全部下完 | 缓存 |
|---|---|---|---|
| 华为云 | 175ms | **458ms** | Cache **Hit** |
| 电信 | 492ms | 1441ms | Cache Miss |

**2.3MB 半秒下完——网络、DNS、CDN 全是好的**（国内 DNS 解析给的就是国内 IP）。

### 这三条数据一起说明什么

- **不是墙**：123ms 就返回 401，是 CDN 主动拒绝，不是超时或阻断。
- **不是加速区域选错**：控制台明确是「含中国大陆」，而且国内节点确实在服务（带 token 就 200）。
- **不是「预览环境没发布」**：那种情况**海外也会拦**，而海外不带任何凭证就是 200。
  **差别只在请求来自哪里**——这是最关键的一条不对称。

**最符合证据的解释**：平台默认分配的 `xxx.edgeone.cool` 域名**没有备案**，
国内节点不能对未备案域名提供公开服务；`eo_token` 是「项目所有者/受邀预览」的内部凭证，
走的不是对公众服务那条路。

> **这个结论没有被官方确认过。** 最快的确认办法是提腾讯云工单，一句话：
> 「全球可用区（含中国大陆）项目，使用平台默认 `.edgeone.cool` 域名，
> 中国大陆访问返回 401，是否必须绑定已备案域名？」
> **问出来之后回来更新这一节。**

### 已排除的几处（别再去这里找）

- **安全防护页**：自定义规则「暂无数据」、精准速率限制「暂无数据」、Bot 人机校验「关」——
  没有任何规则能产生 401。而且该页横幅明写：
  「项目域名和部署域名仅适用平台默认安全防护规则，**不支持修改**」。
- **域名管理页**：默认域名状态「已生效」，但 CNAME / HTTPS 配置 / 关联环境 / 操作**四栏全是 `-`**，
  这是平台自动分配的域名，你编辑不了它。

### 要真正上线，只有这条路

1. 买一个域名（腾讯云几十块一年）
2. **个人备案：通常 1–3 周**，这一步 Claude 不碰（涉及身份证）
3. 回到「域名管理 → 添加自定义域名」绑上去

**周末完不成，做计划时按「几周」算。**

## 四、还有一个坑：站打开了，链接也是死的

**这条独立于部署，部署解决了它依然存在。**

点下去都跳**维基百科搜索页**。**维基在国内打不开**，所以对儿子来说这些链接全是死的。

视频那块已经做对了：中文模式优先走 B 站（v110）。

**需要 Ray 拍板，三个选项：**

- **A. 中文模式改走百度百科**（`baike.baidu.com/search?word=…`），英文模式保留维基。
  改动量：`index.html` 里 `wiki()` 一个函数，一行。
- **B. 什么都不改。** 点了白屏，但站内内容（六问、大事记、地点小段、地图）是完整的。
- **C. 中文模式去掉外链**，标题不再可点。

**建议 A**：一行改动，且与视频那块「中文走国内源」口径一致。

## 五、✅ 已验证可用：微信发文件（不用等备案）

`index.html` 是**自包含单文件**。2026-08-14 实测：把它单独拷进一个空目录
（**没有** `sw.js`、`manifest.webmanifest`、`icons/`）打开，功能完整——

色带 140 条 · 标签 126 个 · 共同体 3 条 · 交流事件 22 个 · 卡片含地图与六问钩子全部正常。

**所以主站和六个故事页走同一条路：微信发文件，内置浏览器直接打开。**
2.4MB，微信传文件毫无压力。这是**今天就能让 Jasper 用上**的路径。

代价：没有离线缓存、每次得重新打开那个文件、不能加主屏。内容一样不缺。

同样的方式适用于六个故事页：`tang.html` `qin.html` `han.html` `song.html` `ming.html` `qing.html`
（每个 31–37KB，也都是自包含单文件）。

## 六、部署成功后要顺带验的

1. iPad **关掉 VPN** 打开域名 → 打得开、地图画得出来 → 添加到主屏幕
2. **六个故事页**：`域名/tang.html` · `/qin.html` · `/han.html` · `/song.html` · `/ming.html` · `/qing.html`
   —— 这六页才是直接给 Jasper 的，**主站没有入口链接是有意的**（实验期不导流，见 `TANG-EXPERIMENT.md`）
3. **压缩**：实测国内节点传输 **2362KB**，而本地 `index.html` 是 **2365KB**——
   **几乎一模一样，说明没有 gzip/brotli**。这个站是纯文本，压缩率通常到 1/4–1/5，
   开了之后约 500KB，手机流量和加载时间都省一大截。
   开关在 EdgeOne **站点加速**层（一般叫「智能压缩」），不在 Pages 项目里。

### ⚠ 已知缺口：故事页不支持离线

`sw.js` 的缓存清单里只有 `index.html`，六个故事页既不在清单里、自身也没注册 service worker。
**直接打开故事页时离线不工作**，加到主屏后没网就是白屏。
按计划属「实验通过后的最小整合」（与主站入口链接同一批，见 `TANG-EXPERIMENT.md`），**有意押后**。
改动是 sw.js 加六个文件名 + 各页两行注册 + 升 `CACHE` 版本号。
