# 设计决策记录

## 核心视觉编码(v0 定型)

参照 1931 年《Histomap》。三个编码各管一件事:

1. **横轴 = 时间**,非线性分段(前3500—前1000 压缩,近 500 年放大;断点表 `BP`)。缩放时切换为窗口内线性。
2. **纵向泳道 = 8 个地理区域**,**按经度自东向西**(v8 重排):东亚/东南亚/南亚/草原·中亚/中东·北非/欧洲/撒南非洲/美洲。理由:链上每对相邻泳道都是历史重度互动对,传播曲线与事件竖线最短;中东居中使伊斯兰/基督教的放射状传播紧凑。已知代价:草原↔东亚隔两泳道(造纸/火药曲线大俯冲,视为表达而非缺陷)。
3. **色带 = 文明**:厚度 = 区域内相对影响力(0-1 主观);**颜色跟文明圈走而非区域**——征服与扩张自动显形(蒙古绿横扫欧亚、1500 后西方蓝涌入美非印)。

## 颜色系统

8 文明圈:西方蓝 #2a78d6 / 东亚橙 #eb6834 / 印度青 #1baf7a / 中东黄 #eda100 / 草原绿 #008300 / 非洲紫 #4a3aa7 / 东南亚红 #e34948 / 美洲品红 #e87ba4(深色模式各有对应步,见 CSS 变量)。同圈内用 color-mix 变体(v:0/1/2)区分相邻同色带。全部过色盲模拟校验;曾因深色模式印度青与草原绿 ΔE 不足改亮(#1baf7a),东南亚红与印度青冲突通过"暹罗 1945 并入现代东南亚"避免相邻。**标签+2px surface 缝隙是法定的辅助编码,不可去掉。**

## 信息层级

全景(泳道图)→ 单文明卡(曲线+鼎盛区间条+版图图+速览+叙述+大事记)→ 外链(维基)。
- **大事记**:点事件,锚定在曲线上(叙事与形状互证);中国最细(~110 节点)
- **鼎盛区间条**(v11):经济黄/艺术品红/科技青/思想紫,与曲线同轴——表达"国势与文明维度错位"(如北宋)
- **版图图**:内嵌 world-atlas 110m 海岸线 + 手绘示意多边形;同期文明(影响力≥0.3)标点,距主版图 60° 经度外的列文字
- **传播轨迹**(v7):10 条,贝塞尔曲线+箭头跨泳道,支持分叉(p 指上游索引)
- **时光穿梭**(v21):把静态图变成一部纪录片——竖线扫过时,底部报"此刻全世界都有谁在场、刚刚发生了什么"。**只弹文明兴起/落幕与跨地区交流事件,不弹 844 条大事记**:少而重才有节奏,近代大事记密到会刷屏。时间轴非线性,所以按像素匀速扫——上古几百年一晃而过、近代一年一年慢慢走,正好与信息密度相称
- **地理底图**(v19):版图图上加河流/山脉/沙漠三层——地理常比政治更能解释文明为什么在这里起、又为什么停在那里(两河流域字面上就在两河之间;埃及是沙漠里的一条绿带)。全部手写内嵌,精度约 ±1~2°,与版图多边形同级。**层级严格低于版图**:沙漠 0.55、山脉 0.5 透明度,河流 1.1px 细线,三者都不该抢过文明色带。河名只标真正穿过本文明版图的(用点在多边形内判定,不能用外接矩形——狭长版图的矩形会框进邻居的河)
- **色带标签定位**(v145):老做法是「放在最厚点、居中对齐」,而最厚点常常就是视野边缘——**每个视图都有 4—16 条标签被画布边切掉**(英文中古时代最多切 96px;「现代东南亚」在现代视图下只剩三个字)。改成两步:①按字数估宽,框出「整条标签能完整放下」的 x 区间;②在**厚度 ≥ 峰值 92% 的高原**里挑离可见段中点最近的一处。有明显峰值时高原很窄,标签仍落在峰上(实测唐 742/峰值 713、罗马帝国 166/117、蒙古 1283/1260);而像「现代东南亚」这种几乎等厚的长带,argmax 本来就是噪声,这时自然回到中间(2004/峰值 2025)。放不下就整条不画——**宁可没有名字,也不要半个名字**。效果:12 个视图 × 中英全部 0 条被切,且**标签集合与改动前逐视图完全一致**(用名字集合哈希对照,没有因新规则丢掉任何一条)
- **地图标签优先级**(v19):本文明名字 > 同期文明 > 河名。高优先级先占位,低的绕开;同级冲突时先下移一档、再上移一档,仍冲突就照原位画——宁可挤,不能把名字吞掉
- **共同体层**(v143):第一个既不是色带也不是事件的对象——一群**仍然存在**的国家自愿把一部分主权交上去。
  形态是泳道底部留白里的一条横杠 + 起点图标 ◎,点开是卡片。三条决定各有理由:
  ①**不横跨色带**——1957—2025 的欧洲泳道上只有法/德/英/俄四条,其中只有法德是欧盟成员,
  一道几何括号四条里错两条;它的价值本来也不在框住已有色带,而在说出那些**图上没有色带**的国家还在。
  ②**用中性的 ink-2 不用文明圈色**——八个圈的颜色是有语义的,共同体不属于任何一个圈,借色就是教错。
  ③**标签放横杠下方**——上方那一带被色带占着(实测 1957 后色带最低点 767.2),放上去会插进色带。
  全景下只有 95px(1957 起算;若从 1993 起算只有 45px,放不下标签),缩放到「现代」后展开成 1251px——
  **这一层是给缩放看的**,全景里它只需要够得着、点得开。
- **古都今址**(v16):速览的"中心"格子下加一行灰色小字「今 国:城」。给儿童用户搭一座从古地名到今日世界地图的桥——君士坦丁堡→土耳其伊斯坦布尔、华氏城→印度巴特那。按今属国家归并而非逐个标注,避免"中国、中国、中国"的重复;遗址类地点只给国名

## 交互约定

- 悬停=速览,点击=详情卡;触屏直接点(有透明大触控区)
- 缩放:点时代名或时间轴拖选;⤺ 全景返回
- 语言:中/EN 原地切换,偏好存 localStorage;打开的卡片随切换重渲染
- 所有重建走 buildChart();事件绑定在 scroller 上委托,重建不失效
